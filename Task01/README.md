# Описание структуры файлов данных

## Исходные файлы данных

### ratings.csv
Файл содержит данные о рейтингах пользователей.

**Структура:**
- userId - идентификатор пользователя (целое число)
- movieId - идентификатор фильма (целое число)
- rating - оценка пользователя (число с плавающей точкой)
- timestamp - временная метка (целое число)

### movies.csv
Файл содержит информацию о фильмах.

**Структура:**
- movieId - идентификатор фильма (целое число)
- title - название фильма (строка)
- genres - жанры фильма (строка, разделённая символом |)

### tags.csv
Файл содержит теги, присвоенные фильмам пользователями.

**Структура:**
- userId - идентификатор пользователя
- movieId - идентификатор фильма
- tag - тег (строка)
- timestamp - временная метка

### users.txt
Файл содержит информацию о пользователях.

### occupation.txt
Файл содержит список профессий.

### genres.txt
Файл содержит список жанров.

## Сгенерированные файлы

### ratings_count.txt
Содержит информацию о минимальном и максимальном идентификаторе пользователя:
- Первая строка: минимальный ID и количество записей с этим ID
- Вторая строка: максимальный ID и количество записей с этим ID

Результат анализа:
- Минимальный ID: 1 (232 записи)
- Максимальный ID: 120 (22 записи)

### sqlite.txt
Содержит версию установленной СУБД SQLite и список доступных режимов вывода в утилите sqlite3.

Версия SQLite: 3.53.4
